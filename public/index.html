Фон

Spotify
Где взять Client ID
  1. Открой developer.spotify.com/dashboard и нажми «Create app».
  2. В Redirect URI впиши
  3. Отметь Web API и Web Playback SDK, сохрани, скопируй Client ID сюда.
  4. Для Brave: открой brave://settings/extensions, включи Widevine и перезапусти браузер, иначе Spotify не заиграет.
SoundCloud

Ник это часть ссылки soundcloud.com/ник. Лайки должны быть открыты.

YouTube Music

Плейлист должен быть открыт по ссылке: войти в аккаунт не нужно, Premium тоже. «Понравившиеся» закрыты от посторонних, поэтому для них плеер берёт вход из Brave: в нём должен быть выполнен вход на YouTube, а сам Brave лучше закрыть. Звук берётся через yt-dlp.

Музыка с компа

mp3, wav, flac, m4a, ogg. Подпапки тоже читаются. Название, артист и обложка берутся из файла, а если их нет, из имени «Артист - Трек».

Discord
Как получить Application ID (1 минута)
  1. Открой discord.com/developers/applications и нажми «New Application».
  2. Назови его Sonara: это имя будет в статусе.
  3. На странице General Information скопируй Application ID и вставь сюда.
  4. В Discord включи: Настройки → Конфиденциальность активности → «Делиться активностью».

Сочетания в окне плеера

Нажми на сочетание и затем на новые клавиши. Esc отменяет. Пока ты печатаешь в поле, плеер клавиши не трогает.

Медиаклавиши Windows

Копия библиотеки

Лайки Spotify, SoundCloud и YouTube Music и все плейлисты одним файлом JSON: название, артист, источник, ссылка или id и дата. Файлы лежат в Документы\Sonara\backup.

Последние копии

Восстановление ничего не удаляет и не меняет в аккаунтах: плейлисты с тем же названием дополняются недостающими треками, остальные создаются заново, а лайки каждого сервиса появляются отдельными плейлистами «Лайки … (копия)». Сами лайки в Spotify и SoundCloud плеер вернуть не может, потому что не имеет права их менять.

Плейлисты в M3U

Каждый плейлист отдельным файлом .m3u8 в Документы\Sonara\backup\m3u: ссылки на треки Spotify, SoundCloud и YouTube Music, а для файлов с компа путь к файлу. Один плейлист можно выгрузить кнопкой «M3U» в его шапке.
